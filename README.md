# 굿모닝 노동법! — 출근하면서 쏙쏙 챙기는 직장인 상식

연차 · 퇴직금 · 근로시간 · 임금 · 괴롭힘 · 출산육아 · 산재 · 계약직 · 해고 · 4대 보험까지,
**노동법과 4대 보험을 12스테이지 60문항으로 맞혀 보는 고전 게임풍 퀴즈**입니다.
출근길 폰에서 한 스테이지(5문제)씩 풀도록 만들었습니다.

👉 **https://gam-test-delta.vercel.app**

## 내가 내린 판단

- **60문항 모두 법령 · 시행규칙 원문에 근거합니다.** 국가법령정보센터에서 받은 법률 조문을
  `tools/build_topics.py` 가 읽어 숫자를 꺼냅니다. 숫자를 손으로 옮겨 적지 않습니다.
  실업급여 지급 사유 문항 하나만 판단 기준(통근 왕복 3시간)이 고용보험법 시행규칙 별표 2에 있어,
  그 문항의 한계와 원문 링크에 밝혀 둡니다.
- **근거와 한계를 함께 보여 줍니다.** 결과 화면의 «근거 보기»에 어느 법 몇 조에서 뽑았는지,
  조문 원문 링크, 답이 달라지는 예외(한계)를 적습니다.
- **기준일을 밝힙니다.** 첫 화면 아래와 스테이지마다 «이 데이터의 한계»에 법령 기준일(2026. 11.)과
  시행 예정 개정을 적습니다.
- **해설은 쉬운 말로 씁니다.** 통상임금 → 평소 시급처럼 어려운 말은 괄호로 풉니다.

## 게임 구성

| | |
|---|---|
| 스테이지 | 12개 × 5문항. 숫자는 슬라이더로, 나머지는 4지선다로 답합니다 |
| 하트 · 승진 | 맞힌 문항마다 하트 1개(슬라이더는 오차 20% 안). 하트 5개마다 승진 — 인턴부터 **대표이사**(하트 60개)까지 13단계 |
| 출근길 노선도 | 스테이지를 끝낼 때마다 회사원이 걷고, 묶음이 끝나면 정거장에 닿습니다. 집 → 근로 → 월급 → 휴가 → 보험 → 노무 → 출근, «회사까지 N정거장» |
| 다음 스테이지 바로 가기 | 결과 점수판 바로 아래 — 아직 안 끝낸 다음 스테이지로 이어 풉니다. 마지막 STAGE 12를 끝냈거나 모든 스테이지를 끝냈으면 틀린 문제 풀기로 넘어갑니다 |
| 틀린 문제만 다시 풀기 | 아직 못 맞힌 문항을 스테이지 · 문항 순서대로 5개씩 다시 풉니다. 맞히면 원래 스테이지 하트가 오릅니다. 기록은 문항 id 로 남겨 문항 순서를 바꿔도 어긋나지 않습니다 |
| 출근 완료 프리패스권 | 바로 회사로. 도착한 뒤에는 «처음부터 다시 출근하기»(기록 초기화)로 바뀝니다 |
| 축하 | 출근 완료 · 대표이사 취임 때 픽셀 꽃가루와 8비트 빵빠레(소리 켜기/끄기 있음). 승진 · 축하 창은 뜨자마자 버튼에 포커스가 가서 Enter, 또는 Esc 로 닫힙니다 |
| 공유 | «동료에게 알려주기» — 점수 · 등급 · 직급 · 남은 정거장을 링크에 담습니다 |

진행 기록은 그 브라우저(localStorage)에만 남고 서버로 가지 않습니다.

## 데이터가 오는 길

```
   국가법령정보센터 «DOC 저장»  ─→  data/raw/<법령>.doc
   최저임금위원회 결정현황 표   ─→  data/raw/minimum_wage.html
        ↓  tools/law_to_json.py      조문별 JSON (현행본 · 시행 예정본을 나눠 담음)
   data/raw/<법령>.json              ← git 에도 배포에도 올라가지 않습니다
        ↓  tools/build_topics.py     조문에서 숫자를 뽑아 문항 · 해설 · 근거 · 원문 링크를 씀
   topics/*.json · topics.json       ← 이것만 배포됩니다
```

`build_topics.py` 는 시행 예정 개정이 정답을 바꾸는지도 확인하고, 바꾸지 않으면
«이 데이터의 한계»에 «시행 예정 개정은 정답을 바꾸지 않는다»고 적습니다.

## 법 개정 대비 — 다시 돌릴 때

지금 데이터가 알고 있는 시행 예정 개정입니다. 이 날짜가 지나면 원문을 다시 받아 돌립니다.

| 시행일 | 조문 | 지금 정답에 영향 |
|---|---|---|
| 2026. 11. 27. | 남녀고용평등법 제13조 · 제37조 · 제39조 | 없음 |
| 2026. 12. 8. | 근로기준법 제116조 | 없음 |
| 2026. 12. 10. | 근로기준법 제54조 | 없음 |
| 2027. 6. 10. | 근로기준법 제60조 | 없음 |

```
1. 국가법령정보센터에서 해당 법령을 «DOC 저장» → data/raw/<법령>.doc 로 덮어쓰기
2. python tools/law_to_json.py data/raw/<법령>.doc
3. python tools/build_topics.py       # 정답이 바뀌면 assert 로 멈추거나 값이 바뀐다
4. tools/build_topics.py 맨 위 AS_OF(기준 연 · 월)를 새 기준으로 바꾸고 다시 3
5. git diff topics/ 로 바뀐 정답을 확인하고 올리기
```

최저임금은 해마다 8월 초 고시됩니다. 다음 해 금액이 나오면 `minimum_wage.html` 을 새로 받고
`build_topics.py` 의 `min_wage(27)` 를 다음 해로 바꿉니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 한 장(스테이지 고르기 · 문항 · 결과)과 픽셀 그림(`<symbol>`) |
| `style.css` | 폰 세로 기준. 색과 간격은 맨 위 `:root` 에서만 정합니다 |
| `app.js` | 진행 · 채점 · 하트 · 승진 · 노선도 · 다시 풀기 · 공유. **계산은 전부 여기서 끝납니다** |
| `topics.json` | 스테이지 목록 · 등급 · 반응 문구 · 법령 기준일 |
| `topics/*.json` | 스테이지별 5문항 — 정답 · 해설 · 근거 · 원문 링크 · 한계 |
| `og.png` | 링크 공유 미리보기 그림 |
| `tools/law_to_json.py` | 법령 DOC(RTF) → 조문별 JSON (배포 제외) |
| `tools/build_topics.py` | 조문 → 문항 계산 (배포 제외) |

`docs/` 에는 처음 주제를 고를 때의 메모와 화면 시안을 남겨 둡니다(배포 제외).
